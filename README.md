# Online Banking System

## Project Description

The Online Banking System is a web-based application developed to provide basic banking services through an easy-to-use interface. The system allows users to securely manage their accounts and perform common banking operations online.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL

## Features

- User Registration and Login
- Secure Password Management
- View Account Details
- Check Account Balance
- Credit and Debit Transactions
- Money Transfer
- Transaction History
- Edit User Profile
- Profile Picture Upload
- Account Deletion
- Admin Dashboard
- Admin can view users and transactions
- Logout

## Project Objective

The main objective of this project is to develop a simple web-based banking system that demonstrates user authentication, database management, and basic banking transactions.

## How It Works

1. User registers and creates an account.
2. User logs into the system.
3. User can view account details and balance.
4. User can perform credit, debit, and money transfer operations.
5. All transactions are stored in the MySQL database.
6. Users can view their transaction history.
7. The administrator can manage and view user and transaction information.

## Backend

The backend is developed using **Python Flask**, while **MySQL** is used to store user, account, and transaction data.

## Project Status

This project was developed as an academic CSE project to demonstrate web development, backend programming, and database connectivity.
